numpy-chatbot
Простой чат-бот на русском языке, у которого «мозг» — маленькая нейросеть, написанная только на numpy (без TensorFlow, PyTorch и т. п.). Работает в Pydroid 3 на Android и на обычном компьютере.
Что умеет
Здороваться, прощаться, болтать о делах
Запоминать твоё имя (даже после перезапуска): «меня зовут Максим»
Считать: «посчитай 2+3*4», «10 разделить на 4», «2 в степени 10»
Рассказывать шутки
Говорить время
Как это работает
Фраза разбивается на слова, у каждого берутся первые 5 букв (простой стемминг для русского).
Фраза превращается в вектор «слово есть / нет».
Нейросеть (вход → скрытый слой с ReLU → softmax) определяет тип фразы (намерение).
Бот выбирает случайный ответ из заготовленных для этого намерения.
Имя и калькулятор работают по шаблонам, а не через нейросеть. Калькулятор считает безопасно, без eval().
Запуск
pip install numpy
python chatbot.py
В Pydroid 3: меню → Pip → установить numpy, затем открыть chatbot.py и запустить. Для выхода напиши «пока».
Как добавить свои фразы
Открой chatbot.py и дополни словарь INTENTS: добавь новое намерение с примерами фраз (patterns) и ответами (responses). Бот переобучится сам при следующем запуске. Чем больше разных примеров, тем лучше он понимает.
Файлы
chatbot.py — чат-бот
neural_net.py — пример нейросети на numpy (задача XOR), с которого всё началось
Имя пользователя сохраняется в bot_memory.json (файл создаётся автоматически и не попадает в репозиторий). Чтобы бот забыл имя, удали этот файл.
Ограничения
Бот не генерирует текст, а только выбирает готовые ответы по типу фразы. Это учебный проект.
